---
title: "Validate and resume work"
description: "Close the loop after a Voss harness session."
---

A Voss session is not done until the result is validated and resumable.

## Validate code

Use the project's normal commands:

```bash
pytest -q
npm test
cargo test
```

For Voss language files:

```bash
voss check .
```

## Inspect git state

```bash
git status --short
git diff
```

## Capture follow-ups

Ask Voss to summarize what changed and what remains:

```bash
voss do "summarize the current diff, validation run, risks, and follow-ups"
```

## Check acceptance criteria

With a Jev key configured, get an advisory read on whether your uncommitted changes meet their criteria:

```bash
voss judge review --criterion "expired sessions are rejected" --criterion "focused tests cover the new branch"
```

The answer is advisory and never replaces your own checks.

## Resume work

```bash
voss sessions
voss resume <session-id>
```

<Tip>
Prefer recording decisions and validation in project memory (`/save <note>`) rather than relying only on chat history.
</Tip>
